SHIMLA MANALI TOURISM - HOME PAGE DELIVERABLES

1. COMPLETE HOME PAGE SOURCE

The complete source is in the project folder:
- index.html - Home page markup and content
- css\style.css - Page styling and responsive layouts
- js\main.js - Page interactions and animations
- assets\ - Images, icons, and other static assets
- server.js - Local development server
- package.json - Project run scripts

2. LOCAL SETUP

Requirements:
- Install Node.js (LTS recommended).
- Git is needed only if cloning the repository.

Get the source:
  git clone https://github.com/akash37521-villan/Shmila_manali_Tour.git
  cd Shmila_manali_Tour

Run the website:
  npm start

Open this address in a browser:
  http://localhost:3000

The project has no third-party npm dependencies, so npm install is not
required. Stop the local server with Ctrl+C.
