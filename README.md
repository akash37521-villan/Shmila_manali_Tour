## 📖 About

Shimla Manali Tourism (SMT) is a Himachal-based travel company website built to showcase curated tour packages, group departures, and destinations across Himachal Pradesh, and to turn visitors into trip inquiries and bookings.

The site is a single-page, mobile-responsive experience with a lead capture form, a package booking modal, and a WhatsApp chat shortcut.

## ✨ Features

- **Hero section** with clear calls to action: *Plan Your Trip* and *Contact Us*
- **Trust badges:** Rooted in Himachal, Premium Local Network, Secure & Seamless Bookings, Dedicated Guest Support
- **Curated travel packages** with category filters:
  - All Packages
  - Budget
  - Premium
  - VIP
  - Luxury
  - Hidden Gems of Himachal
- **Package cards** showing duration, rating, original vs. discounted price, and seat-availability badges
- **About / Discover Himachal** section with company highlights and stats (travelers hosted, verified stays, destinations covered, guest satisfaction)
- **Destination explorer** for Shimla and Manali
- **Upcoming group departures**, including the Spiti Valley Winter Expedition (4x4)
- **Testimonials** section based on Google reviews
- **Travel Diaries (blog)** for travel tips, seasonal guides, and local stories
- **Lead form:** *Plan Your Dream Trip* (name, phone, travel date, trip type) with a free quote promise
- **Package booking modal:** reserve with a small token amount, pay the rest on hotel check-in
- **Contact and office details** with a Google Maps "Get Direction" link
- **Floating WhatsApp button** to chat with a local expert
- **SEO-ready** meta description and keywords

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- [Git](https://git-scm.com/)
- Optional: [Node.js](https://nodejs.org/) if you use a local dev server or build tooling


### Deploy to Vercel

```bash
npm i -g vercel
vercel
```

Or import the repository from the [Vercel dashboard](https://vercel.com/new). Every push to the main branch deploys automatically.

## ⚙️ Customization

- **Packages:** edit the package cards (title, duration, rating, price, seats left, image).
- **Departures:** update the group departure cards with new trips and dates.
- **Testimonials:** replace placeholder reviews with real customer reviews.
- **Blog posts:** add or edit the Travel Diaries cards.
- **Contact details:** update phone, email, and address in the header, contact section, and footer.
- **WhatsApp link:** change the number or prefilled message in the `wa.me` URL.
- **Social links:** point the Facebook, YouTube, and Instagram icons to your real profiles.
- **SEO:** update the page title, meta description, and meta keywords in `<head>`.
