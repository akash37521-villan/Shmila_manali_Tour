# Shimla Manali Tourism

A responsive travel website for discovering curated Shimla and Manali stays, tour packages, and Himalayan experiences.

## Run locally

Requires Node.js. No package installation is needed.

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Interface highlights

- Responsive navigation, package cards, destinations, forms, and footer.
- Masked hero headline, subtle Himalayan image drift, staggered scroll reveals, and a reading-progress bar.
- Animated statistics and image hover effects, with reduced-motion accessibility support.
- Honors the visitor's reduced-motion accessibility preference.
- Playfair Display headings paired with DM Sans body text.

## Project structure

- `index.html` — site content and page structure
- `css/style.css` — design tokens, components, animation, and responsive layout
- `js/main.js` — navigation, booking forms, package filters, and scroll effects
- `assets/images/` — logos and site photography
